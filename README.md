# Tiny Stack VM

A tiny, exact interpreter for make.fun's tiny stack ISA — 32-bit wrapping arithmetic, exact trap codes, 1,000,000-step and 65,536-byte output limits.

## Run locally

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```

Reads `/input/<id>/program.bin` + `input.bin`, writes `/output/<id>/stdout.bin` + `exit.txt` for every instance.
